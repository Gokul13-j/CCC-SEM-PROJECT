About LCS

The Longest Common Subsequence (LCS) problem is a classic dynamic programming problem. It finds the longest subsequence present in both given sequences, maintaining the relative order of elements.

Example:

String 1: "AGGTAB"

String 2: "GXTXAYB"

LCS: "GTAB" (length: 4)
